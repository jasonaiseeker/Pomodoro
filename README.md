# Pomodoro

轻量级 Windows 悬浮番茄钟，计划使用 Rust + Slint，覆盖置顶、系统托盘、可靠计时与本地数据管理。

当前阶段：需求、架构提案和可编辑 UI 设计。所有架构选择等待项目所有者审批；业务代码开发在 Notion 文档与 Figma 原型确认后启动。
