# Pomodoro

轻量级 Windows 悬浮番茄钟，计划使用 Rust + Slint，覆盖置顶、系统托盘、可靠计时与本地数据管理。

当前阶段：需求、架构提案和可编辑 UI 设计。所有架构选择等待项目所有者审批；业务代码开发在 Notion 文档与 Figma 原型确认后启动。

## 协作入口

- [GitHub](https://github.com/troywjz/Pomodoro)：Issues、分支与 Pull Requests
- Notion：需求、架构、决策和评审记录
- Figma：可编辑 UI 原型与交互说明
- [团队规范](AGENTS.md)

初始仓库只包含项目说明与协作规范。后续规划通过文档 PR 提交，PR 合并与发布由项目所有者审批。
