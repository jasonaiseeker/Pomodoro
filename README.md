# Pomodoro

轻量级Windows悬浮番茄钟，目标使用Rust+Slint，覆盖可靠计时、置顶、托盘、Hyper-V工作场景和本地数据。

当前是需求、UI v2和关键架构评审阶段。组织已重整为稳定模块责任、短任务session和有限并行，业务源码与Cargo工程保持待启动。
